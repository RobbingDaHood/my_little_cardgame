# Vision & Roadmap Suggestions (from B2.6 Woodcutting Balance Tuning)

These suggestions are based on learnings from tuning woodcutting balance
to meet the tier-based yield/durability targets from issue #66.

## vision.md suggestions

1. **Type-specific cost profiles as a design pattern** — Woodcutting balance
   required differentiated durability costs per chop type (cheap LightChop
   vs expensive PrecisionChop) to create meaningful strategy separation.
   Vision.md should document this as a general gathering-discipline pattern:
   when all card types share uniform costs, strategies converge regardless
   of max_plays or multiplier tuning. Cost variation is the primary lever
   for strategic differentiation in auto-draw disciplines.

2. **max_plays × auto-draw interaction** — With max_plays=8 and auto-draw,
   players see 5 known cards plus 3 unknown draws. This creates a natural
   information asymmetry that rewards pattern-building (plan around known
   cards, gamble on draws). Vision.md should document this 5+3 split as
   the intended strategic depth model for pattern-based disciplines.

3. **Durability as the true session limiter** — Auto-draw eliminates card
   depletion, making durability the sole session-bounding resource. Vision.md
   should emphasize that all gathering disciplines share this model: the
   durability budget determines how many encounters are available, and
   per-encounter efficiency (yield/durability) is the core optimization axis.

## roadmap.md suggestions

1. **Per-discipline cost differentiation pass** — After woodcutting, other
   gathering disciplines should be checked for uniform-cost convergence.
   If mining/herbalism/fishing show similar strategy flattening, introduce
   type-specific cost profiles following the woodcutting pattern.

2. **Balance doc: add simulation results section** — The woodcutting_balance
   doc explicitly says simulation results belong in PRs, not the doc. But
   having a "Latest Tuned Values" table showing the most recent passing
   config would help future tuners establish baselines without re-running
   simulations. Consider adding a brief reference table.

3. **Multi-effect card balance investigation** — Woodcutting cards with
   multiple effects (e.g., heavy_chop + light_chop) generate 2+ chop values
   per play. With max_plays=8, this means 12-20+ chop values per encounter,
   making high patterns (Five/Six of a Kind) very common. Consider whether
   multi-effect cards need cost scaling or whether the pattern multiplier
   table already accounts for this via sqrt inverse-probability scaling.

## woodcutting_balance.md suggestions

1. **Document tuned config values** — The Config Parameters section lists
   categories but not current values. After B2.6 tuning:
   - max_plays: 8
   - Durability costs: type-specific (LightChop 10-25, MediumChop 25-50,
     HeavyChop 45-85, PrecisionChop 55-95, SplitChop 35-70)
   - Stamina costs: 20-50
   - Health costs: 30-60
   - Base reward: 28 Lumber
   - Pattern multipliers boosted (Triple 3.0×, Four of Kind 5.0×,
     Full House 6.0×, Value Triple 7.0×, Value Quads 12.0×)
